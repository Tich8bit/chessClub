# chessClub — консольная система шахматного клуба

Учебный проект на C++20: учёт игроков и тренеров, турниры, тренировки, матчи,
рейтинги и аналитика. Интерфейс на Qt пока не подключён — сначала консоль.

## Структура

- `cppFolder/` — реализация (16 файлов)
- `hFolder/` — заголовки, `hFolder/exceptions/` — иерархия исключений
- `club.txt` — сохранённое состояние клуба
- `README.md`

## Сборка (MinGW g++ из msys2 UCRT64)

```
g++ -std=c++20 cppFolder\*.cpp -IhFolder -o chessClub.exe
```

## Запуск

```
chessClub.exe
```

Стартовое меню: `1` — тестовые данные, `2` — загрузка из `club.txt`, `0` — выход.
Дальше: 1.Игрок 2.Тренер 3.Турнир 4.Тренировка 5.Матч 6.Таблица 7.Сохранить 8.Показать 0.Выход.

## Заметки

- `club.txt` ищется в текущем каталоге — запускай из корня проекта.
- Исходники в UTF-8 без BOM; `main.cpp` выставляет `CP_UTF8` для консоли.
- В коде есть `#include "basefunction.h"`, а файл называется `baseFunction.h`.
  На Windows работает, на Linux/case-sensitive ФС — нет. Стоит привести к одному виду.
- GUI на Qt 6 будет добавлен позже отдельным проектом; исходный `ChessClubGUI`
  остаётся в `C:\chess`.
